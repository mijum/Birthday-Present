# 🎂 Birthday Present — A Birthday Story for You ♡

A romantic, interactive birthday storytelling website featuring emotional handwritten letters in Bengali, an adorable Panda animation video with surprise celebration, shared memories gallery with custom anime illustrations, interactive cake cutting, and background music.

## ✨ Features

- **🎬 Panda Celebration Video**: Full-screen 1080p animated panda celebration with custom audio toggle and replay controls.
- **🎉 Surprise Birthday Reveal**: As the video ends, a festive surprise celebration bursts onto the screen with floating 3D balloons, confetti fireworks, and greeting text.
- **💌 Bengali Handwritten Love Letters**: Deeply emotional, poetic love letters written in Bengali with English salutations, formatted in a vintage envelope and stationery design.
- **📸 Memories Gallery**: 6 custom romantic memory moments featuring anime companion scenes (starlit city rooftop, cozy cafe, sunset beach walks, riverside adventures, rainy umbrella strolls).
- **🎂 Interactive Cake & Candles**: Blow out candles using microphone blow-detection or tapping, accompanied by dynamic cake cutting and particle effects.
- **🎵 Romantic Background Music**: Automatically plays background track from the start with interactive gesture fallback and audio controls.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4 + Vanilla CSS animations
- **Animation**: Motion (Framer Motion)
- **Effects**: Canvas Confetti, Web Audio API Synthesizer
- **Typography**: Google Fonts (*Noto Serif Bengali*, *Hind Siliguri*, *Playfair Display*)

## 🚀 Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mijum/Birthday-Present.git
   cd Birthday-Present
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local dev server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

---

## 🌐 Deploy to Render

1. Create a new **Static Site** on [Render](https://render.com).
2. Connect this GitHub repository: `https://github.com/mijum/Birthday-Present`.
3. Set the following settings:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
4. Click **Create Static Site**!
